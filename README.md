# File Manager — файловий менеджер

**Орієнтир:** 2 тижні (тижні 1–2)

## Мета
Навчитися безпечно працювати з файловою системою Windows, обробляти помилки та відокремлювати інтерфейс від логіки.

## Функціональні вимоги
- Перегляд каталогу: імена, типи, розміри, час зміни; сортування та фільтр за розширенням.
- Створення каталогів, копіювання, переміщення, перейменування, видалення з підтвердженням. Конфлікти імен: пропустити / замінити / скасувати.
- Рекурсивний пошук за маскою; звіт про недоступні файли без аварійного завершення.
- Шляхи з пробілами та українськими символами. Symlink і junction не обходити рекурсивно за замовчуванням.

## Технології
`std::filesystem`, `std::error_code`, потоки вводу/виводу, `std::chrono`. На межі з Windows API — UTF-16, у застосунку — UTF-8.

## План
1. Описати команди та політику перезапису. CMake-проєкт і окремий модуль файлових операцій.
2. Перегляд, сортування, навігація. Перевірити порожні й недоступні каталоги.
3. Копіювання та переміщення, потім перейменування й видалення. Відображати частково виконані операції.
4. Рекурсивний пошук; захист від копіювання каталогу в себе або у власний підкаталог.
5. Тести у тимчасових каталогах; приклад роботи та Release-збірка.

## Критерій готовності
- [ ] Операції працюють із вкладеними каталогами й українськими назвами
- [ ] Відмова доступу не завершує програму
- [ ] Сценарії перезапису перевірені тестами

## Розширення
Фонове копіювання з прогресом і скасуванням; порівняння каталогів.
